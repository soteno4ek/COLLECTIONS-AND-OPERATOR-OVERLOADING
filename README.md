каждого работника известно, какие языки он знает. Определить для каждого языка, какие из них

<Фамилия><Имя><Школа><Балл>

Пример входной строки:

Пример выходных данных, когда найдено два лучших:

Если больше двух учеников набрали высший балл, то программа должна вывести их количество.

8
Если высший балл набрал один человек, а следующий балл набрало несколько человек, то
программа должна вывести только фамилию и имя лучшего. Пример вывода в этом случае:
Иванов Сергей

# Задание 7

## Задача 7

### Текст задачи

Перегрузка операций. 
Time Унарные операции:
-- вычитание минуты из объекта типа Time
Операции приведения типа:
byte (явная) – результатом является количество часов (минуты
отбрасываются);
bool (неявная) – результатом является true, если часы и минуты не равны
нулю, и falseв противном случае.
Бинарные операции:
+ Timet, беззнаковое целое число (лево- и правосторонние операции) –
добавление минут к времени.
+ Timet1, Timet2 – сложить два времени.

### Алгоритм решения

1. Перегрузить унарный декремент `operator --(Time t)`: перевести время в минуты, вычесть 1 (при переходе ниже 0 установить 1439 минут, то есть 23:59) и вернуть новый объект `Time`
2. Перегрузить явное приведение `explicit operator byte(Time t)`, возвращающее поле `_hours`
3. Перегрузить неявное приведение `implicit operator bool(Time t)`, возвращающее `_hours != 0 || _minutes != 0`
4. Перегрузить бинарный оператор `+` для пары `(Time t, uint minutes)` с нормализацией по модулю 1440 минут и реализовать симметричную перегрузку `(uint minutes, Time t)` через вызов `t + minutes`
5. Перегрузить бинарный оператор `+` для сложения двух объектов `(Time t1, Time t2)` с учетом перехода через 24 часа и протестировать все операции в `Program.cs`
